# Marketing Campaign Performance Analysis | Excel Dashboard

## Project Overview

This project focuses on analyzing marketing campaign performance using Microsoft Excel. The objective is to transform raw campaign data into meaningful insights that help evaluate marketing effectiveness across different channels, regions, and time periods.

The project involves data cleaning, data transformation, calculated metrics, Pivot Table analysis, and an interactive dashboard to monitor important marketing performance indicators.

## Project Objectives

- Analyze marketing campaign performance across different advertising channels.
- Evaluate campaign spending and revenue generation.
- Understand monthly trends in revenue, impressions, and clicks.
- Compare conversion rates across marketing channels.
- Analyze budget allocation and overall campaign profitability.
- Build an interactive dashboard to support data-driven decision-making.

## Dataset Description

The workbook contains two primary datasets:

- **Raw Data:** Original marketing campaign dataset.
- **Clean_Data:** Cleaned and transformed dataset with additional calculated columns.

The dataset contains 500 campaign records with the following attributes:

| Column | Description |
|---|---|
| Campaign_ID | Unique campaign identifier |
| Date | Campaign date |
| Channel | Marketing platform |
| Region | Campaign region |
| Budget | Allocated campaign budget |
| Spend | Actual campaign expenditure |
| Impressions | Number of times advertisements were displayed |
| Clicks | Number of advertisement clicks |
| Conversions | Number of successful conversions |
| Revenue | Revenue generated by campaigns |

## Data Cleaning and Transformation

The raw dataset was prepared for analysis by applying Excel functions and creating additional analytical columns.

### Data Cleaning

- Used `TRIM()` to remove unnecessary leading and trailing spaces.
- Used `CLEAN()` to remove unwanted non-printable characters.
- Used `PROPER()` to standardize text formatting.
- Maintained consistent channel and region names.
- Linked the cleaned dataset to the original raw data.

### Feature Engineering

The following calculated columns were created to support campaign performance analysis:

| Metric | Formula | Purpose |
|---|---|---|
| Year_Month | `TEXT(Date,"yyyy-mm")` | Monthly analysis |
| CTR | Clicks / Impressions | Measures advertisement click-through performance |
| Conversion Rate | Conversions / Clicks | Measures conversion effectiveness |
| ROAS | Revenue / Spend | Measures return on advertising spend |
| Profit | Revenue - Spend | Calculates campaign profit |
| Profit Margin | Profit / Revenue | Measures profit relative to revenue |
| CPA | Spend / Conversions | Measures cost per acquisition |
| CPC | Spend / Clicks | Measures cost per click |

## Analysis and Pivot Tables

Pivot Tables were created to summarize campaign performance and explore different business dimensions.

The analysis includes:

1. **Channel Performance:** Comparison of total spending and revenue across marketing channels.
2. **Monthly Revenue Trend:** Evaluation of revenue generation over time.
3. **Campaign Engagement:** Analysis of impressions and clicks across months.
4. **Budget Allocation:** Comparison of allocated budgets across channels.
5. **Conversion Analysis:** Comparison of average conversion rates across marketing channels.
6. **Overall Performance:** Evaluation of average ROAS and profit margin.

## Dashboard Overview

The interactive Excel dashboard provides a consolidated view of marketing campaign performance.

### Key Performance Indicators (KPIs)

- Average ROAS: 2.36
- Average Profit Margin: 8.07%
- Total Impressions: 62,386,067
- Total Clicks: 1,814,121
- Total Conversions: 184,526

### Dashboard Visualizations

- Total Spend and Revenue by Channel
- Monthly Revenue Trend
- Total Impressions and Clicks Over Time
- Budget Allocation by Channel
- Conversion Rate by Channel

### Interactive Filters (Slicers)

The dashboard includes slicers that allow users to dynamically filter the analysis by:

- Year_Month
- Channel
- Region

These filters make it easier to explore campaign performance from different perspectives.

## Key Observations

- Instagram recorded the highest average conversion rate among the analyzed channels at approximately 11.86%.
- Instagram generated the highest total revenue among the five marketing channels.
- April 2025 recorded the highest monthly revenue in the analyzed period.
- June 2025 recorded the lowest monthly revenue in the dataset.
- Overall average ROAS was approximately 2.36, with an average profit margin of 8.07%.

*These observations are based on the aggregated results in the project workbook.*
